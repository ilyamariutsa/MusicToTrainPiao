# Piano samples

Salamander Grand Piano V3 — Yamaha C5, recorded by Alexander Holm.
License: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

30 MP3 files, one every minor third from A0 to C8 (`Ds4` = D♯4, `Fs4` = F♯4),
taken from the Tone.js sample set: https://tonejs.github.io/audio/salamander/
`src/renderer/src/lib/audio.ts` loads them into a `Tone.Sampler`, which repitches the keys in between.

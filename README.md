# NotaMentor

Настольное приложение для изучения мелодий на пианино: ноты скрипичного и басового ключей, звук, аппликатура, импорт MusicXML/MIDI и классический установщик Windows.

## Что умеет

- Партитура на двух нотоносцах и подсветка текущих нот
- Звук встроенного пианино, темп, разбор по фразам, правая / левая / обе руки
- Режим **«Жди меня»**: пьеса ждёт правильных клавиш
- Цифры пальцев на клавиатуре (1 — большой)
- Тренажёр нот: скрипичный, басовый или оба ключа
- Разминка: гаммы, пять пальцев, арпеджио, каданс I–IV–V–I
- Метроном, избранное, группы сложности, статистика занятий
- Импорт **MusicXML / MXL / MIDI / .nota** — файлы остаются в вашей библиотеке
- Ввод с MIDI-клавиатуры или с клавиатуры компьютера

## Запуск в разработке

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

## Установщик для друзей

```bash
npm run dist
```

Готовый файл: `release/NotaMentor-Setup-<версия>.exe` (версия — из `package.json`).

Это обычный установщик Windows (NSIS): можно выбрать папку, создаются ярлыки на рабочем столе и в меню «Пуск», при обновлении они сохраняются. Друзья устанавливают его как любое другое ПО. Интернет для встроенных пьес и тренажёра не нужен.

Чтобы `NotaMentor.exe` получил свою иконку и название (а не «Electron»), сборщику нужен набор утилит winCodeSign. Без режима разработчика Windows он не распаковывается сам из-за двух символьных ссылок для macOS. Тогда распакуйте его вручную один раз:

```bash
node_modules\7zip-bin\win\x64\7za.exe x winCodeSign-2.6.0.7z -o"%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0"
```

(команда из папки проекта, архив предварительно скачан в неё)

Архив — https://github.com/electron-userland/electron-builder-binaries/releases/download/winCodeSign-2.6.0/winCodeSign-2.6.0.7z, ошибки про `darwin/*.dylib` можно игнорировать.

## Откуда брать ноты

1. [MuseScore](https://musescore.org) или musescore.com — «Экспорт» → MusicXML (лучше всего сохраняет ключи и пальцы).
2. MIDI, если MusicXML нет. Ноты восстановятся, но штрихи и точные длительности бывают грубее.
3. Текстовый формат `.nota` — удобно набросать мелодию вручную.

Пример `.nota`:

```text
id: my-song
title: Моя мелодия
composer: Я
group: custom
tempo: 90
time: 4/4
key: 0
---
RH: C4q.1 D4q.2 E4q.3 F4q.1 G4h.5
LH: C3h.5 G2h.1 C3w.5
```

Длительности: `w` целая, `h` половинная, `q` четверть, `e` восьмая, `s` шестнадцатая, суффикс `d` — с точкой. После точки — палец: `C4q.1`.

## Клавиатура компьютера

- `Z X C V B N M` — белые клавиши малой октавы, `S D G H J` — чёрные
- `Q W E R T Y U I` — первая октава, `2 3 5 6 7` — чёрные

## Где хранятся данные

Папка пользователя Windows: `%APPDATA%\NotaMentor\library`.
Её можно открыть из раздела «Настройки».
